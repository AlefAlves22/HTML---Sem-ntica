# ☕ Página Institucional - Grão de Ouro

Página web institucional temporária desenvolvida para a empresa fictícia **Grão de Ouro**, especializada em cafés especiais e serviços da cadeia cafeeira. 

Este projeto foi desenvolvido como parte de uma atividade prática de HTML5 e organização de arquivos web.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** (Estruturação semântica de conteúdo)
